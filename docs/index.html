Installer en 3 étapes

L'application n'est pas encore sur le Play Store : on l'installe directement.

Téléchargez

Touchez « Télécharger pour Android » et ouvrez le fichier RecuFacile-CI.apk.

Autorisez

Si Android le demande, autorisez l'installation depuis votre navigateur (« sources inconnues »).

Configurez

Entrez le nom de votre boutique et votre numéro : vous êtes prêt à créer votre premier reçu.

Questions fréquentes

Est-ce vraiment gratuit ?

Oui. Aucun abonnement, aucune limite de reçus, aucune fonction essentielle payante.

L'application envoie-t-elle de l'argent ?

Non. Elle enregistre seulement le mode de paiement et le montant déclarés. Aucun transfert d'argent.

Où sont stockés mes reçus ?

Uniquement sur votre téléphone. Vous pouvez exporter une sauvegarde (Drive, WhatsApp, e-mail) depuis « Ma boutique ».

Que se passe-t-il si je change de téléphone ?

Exportez une sauvegarde sur l'ancien téléphone, puis utilisez « Restaurer une sauvegarde » sur le nouveau.

Est-ce sûr d'installer l'APK ?

L'application est open source : son code est public sur GitHub et l'APK est construit automatiquement à partir de ce code.
